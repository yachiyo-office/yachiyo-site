# 【内部資料】建設業許可 加算料金表（非公開）

- 作成日：2026-08-02
- 用途：見積り作成時の社内基準。サイトには掲載しない。
- 運用方針：当面は「基本料金＋事前見積り」方式。実案件を数件こなして工数感を掴んだ後、公開への切り替えを検討する。
- 金額はすべて税込。

## 1. 基本料金（サイト掲載中の金額）

| 種別 | 報酬額 | 法定費用 |
|---|---|---|
| 新規申請（知事・個人） | 99,000円〜 | 90,000円 |
| 新規申請（知事・法人） | 121,000円〜 | 90,000円 |
| 新規申請（大臣） | 176,000円〜 | 150,000円 |
| 更新申請 | 66,000円〜 | 50,000円 |
| 業種追加 | 55,000円〜 | 50,000円 |
| 般・特新規 | 132,000円〜 | 90,000円 |
| 決算変更届（1期分） | 33,000円〜 | なし |
| 決算変更届（未提出分・1期につき） | 27,500円〜 | なし |
| 各種変更届 | 16,500円〜 | なし |

※基本料金の適用条件：標準的な書類が揃っている場合（専技は国家資格で証明、経管は許可業者での役員経験＋資料完備）。

## 2. 専任技術者（営業所技術者）の証明方法による加算

| 証明方法 | 加算額 | 工数の目安 |
|---|---|---|
| 国家資格（施工管理技士・建築士 等）で証明 | ＋0円 | 資格証の写しのみ |
| 指定学科卒業＋実務経験3〜5年で証明 | ＋33,000円 | 卒業証明書＋経験期間分の裏付資料 |
| 実務経験10年で証明 | ＋55,000円 | 10年分の契約書・注文書・請求書＋入金記録の収集・整理 |

※経管と専技の経験証明が同一資料で共通する場合は、専技側の加算を半額に減額（例：10年証明なら＋27,500円）。

## 3. 経営業務の管理責任者（経管）の証明による加算

| 状況 | 加算額 | 工数の目安 |
|---|---|---|
| 建設業許可業者での役員経験（資料完備） | ＋0円 | 登記事項証明書等で確認可能 |
| 無許可業者での経営経験を工事実績で証明 | ＋44,000円 | 注文書・請求書等の精査、行政との事前協議 |
| 「準ずる地位」「補佐経験」での証明 | ＋77,000円 | 組織図・稟議書等の追加資料、協議難度が高い |

## 5. 見積り例（検算用）

| ケース | 計算 | 報酬合計 | 総額（法定費用込み） |
|---|---|---|---|
| 法人・知事新規、専技は資格者、経管は許可業者役員 | 121,000＋0＋0 | 121,000円 | 211,000円＋実費 |
| 法人・知事新規、専技は実務経験10年 | 121,000＋55,000 | 176,000円 | 266,000円＋実費 |
| 個人・知事新規、専技10年＋経管を無許可業者経験で証明 | 99,000＋55,000＋44,000 | 198,000円 | 288,000円＋実費 |

※地域相場（実務経験証明ありの新規：報酬15〜25万円）に収まることを確認済み。

## 6. 参考にした相場データ

- 日本行政書士会連合会「令和7年度報酬額統計調査」：新規・知事の最頻値 個人110,000円／法人165,000円、決算変更届の最頻値 33,000円
- 同業事務所の公開加算表の例
  - 実務経験10年の証明：＋40,700〜88,000円
  - 学卒＋実務経験：＋25,300〜55,000円
  - 経管の無許可業者証明・準ずる地位：＋25,300〜132,000円
  - 書類代理取得：2,200円／通

## 7. 運用メモ

- 加算が見込まれる案件は、必ず**着手前に**見積書を提示する（サイトの注記と整合）。
- 受任後に想定外の資料不足が判明した場合も、追加見積りを提示してから作業を進める。
- 実案件3〜5件の実働時間を記録し、加算額が工数に見合っているか半年を目安に見直す。
