## はじめに

建設業の許可が下りたあとに、よく聞かれるのが「契約書は、何を書いておけばよいか」です。

建設工事の請負契約は、口約束では足りません。当事者は、対等な立場の合意で公正な契約を結び、信義に従って誠実に履行します（建設業法第18条）。そのために、契約を結ぶときには、法律が定める事項を**書面に書いて、署名または記名押印をし、お互いに交付**しなければなりません（第19条第1項）。

災害時などでやむを得ない場合を除き、交付は**工事の着手前**です。施工の途中や、工事が終わってから書面を渡すのでは、第19条第1項に合いません。これは、許可が必要な規模の工事に限りません。軽微な建設工事の請負契約も対象です。

かつては「14項目」と説明されることが多くありました。いまの第19条第1項は、工事を施工しない日・時間帯などが加わり、番号も変わっています。国土交通省の「発注者・受注者間における建設業法令遵守ガイドライン」（令和8年1月・第8版）は、契約書面に書く事項として**15項目**を整理しています。

---

## 書面に書く15項目

次が、ガイドラインが挙げている事項です。条文の第16号は「その他国土交通省令で定める事項」です。ガイドラインの15項目に、省令がさらに項目を足していないかを、契約書を作るときに確認してください。

| 号 | 書くこと | 補足 |
|---|---|---|
| 1 | 工事内容 | 「○○工事一式」だけでは足りない。責任施工の範囲と施工条件を具体的に |
| 2 | 請負代金の額 | |
| 3 | 工事着手の時期と工事完成の時期 | |
| 4 | 工事を施工しない日または時間帯の定めをするときは、その内容 | 定めをする場合 |
| 5 | 請負代金の全部または一部の前金払、または出来形部分に対する支払の定めをするときは、その時期と方法 | 定めをする場合 |
| 6 | 設計変更、着手の延期、工事の全部または一部の中止の申出があったときの、工期の変更、請負代金の変更、損害の負担と、その額の算定方法 | |
| 7 | 天災その他の不可抗力による工期の変更、損害の負担と、その額の算定方法 | |
| 8 | 価格等の変動または変更に基づく、工事内容の変更または請負代金の変更と、その額の算定方法 | 「変更しない」とは書けない |
| 9 | 工事で第三者が損害を受けたときの賠償金の負担 | |
| 10 | 注文者が資材を提供し、または建設機械などを貸すときは、その内容と方法 | 提供・貸与がある場合 |
| 11 | 完成を確認する検査の時期と方法、引渡しの時期 | |
| 12 | 工事完成後の請負代金の支払の時期と方法 | |
| 13 | 種類または品質が契約に適合しないときの責任、またはその履行のための保証保険などの定めをするときは、その内容 | 定めをする場合。旧来の「瑕疵担保」という整理ではない |
| 14 | 履行遅滞その他の債務不履行のときの遅延利息、違約金その他の損害金 | |
| 15 | 契約に関する紛争の解決方法 | |

第4号、第5号、第10号、第13号は、「その定めをするとき」に内容を書きます。定めをしないときも、「定めはない」と書いておくと、あとから「口頭で約束した」という争いになりにくくなります。

### 特に抜けやすいところ

**工事内容**は、いちばん曖昧になりやすい項目です。ガイドラインは、受注者の責任施工の範囲と施工条件を具体的に書き、「○○工事一式」という書き方は避ける、としています。

**価格等の変動**は、書いていないだけでは足りません。書いてあっても「変更しない」「変更を認めない」と、協議を前提としない内容だと、価格の変動を受けて契約を変えるという法律の趣旨に沿わず、第19条第1項に違反するとガイドラインは説明しています。金額の算定は「協議して定める」とし、協議では変動の内容などを考慮する、という書き方が例示されています。

**契約不適合**は、民法改正前の「瑕疵担保」という見出しのままのひな形が残っていることがあります。いまの第13号は、目的物の種類または品質が契約の内容に適合しない場合の責任です。古いひな形を使うときは、文言をそのまま使わず、いまの条文に合わせて読み替えてください。

## 追加・変更は、着手前にもう一度書面にする

請負代金や工期など、第19条第1項の事項に当たる内容を変えるときは、その変更の内容を書面に書き、署名または記名押印をして、お互いに交付します（第19条第2項）。

「あとで金額は相談」のまま追加工事に入る、という進め方は、この規定に合いません。変更の書面は、追加・変更の工事に着手する前に交付します。

変更の書面にも、変わった部分だけでなく、工期や代金の算定方法が読み取れるようにします。当初の契約書に算定方法が書いてあれば、変更書面はその方法に沿って金額と工期を書きます。

---

## 下請契約でも同じです

第19条は、発注者と元請の間だけのルールではありません。建設工事の請負契約の当事者すべてが対象です。元請が一次下請と結ぶ契約も、一次下請がさらに出す契約も、同じように書面が必要です。

下請代金の支払時期には、別に第24条の3以下のルールがあります。第19条の記載を満たしていても、下請代金の支払期日まで満たしているとは限りません。この記事は、契約書面に書く事項の説明です。

見積りについても、建設業者は、工事の種別ごとの材料費、労務費その他の経費の内訳と、工程ごとの作業およびその準備に必要な日数を明らかにして、見積書を交付する努力義務があります（第20条）。ガイドラインは、契約の際に、その見積内容を考慮するとしています。

---

## 電子契約と、注文書・請書

書面の交付に代えて、相手方の承諾を得たうえで、電子情報処理組織その他の情報通信技術を使う方法ができます（第19条第3項）。承諾の手続は政令と省令にあり、相手方はあとから承諾を撤回できます。電子でも、上の15項目の記載は必要です。

国土交通省は、「電磁的措置による建設工事の請負契約の締結に係るガイドライン」（令和7年9月）を出しています。電子契約にするときは、こちらを参照します。

注文書と請書で契約する場合、基本契約書と注文書・請書を合わせて、第19条第1項の事項が記載されている必要があります。注文書・請書への署名または記名押印を必ずしも要しない、とされているのは、次のすべてを満たす場合です（「注文書及び請書による契約の締結について」令和7年9月30日最終改定）。

- 注文者が、消費者契約法の「消費者」ではない
- 基本契約を結ぶときに、ガイドラインの考え方に従い、対等なパートナーシップにあることを双方で確認している
- 基本契約を結ぶときに、双方の間に反復継続した取引の実績があることを確認している

この3つを満たさない取引で、署名も記名押印もない注文書だけを渡しても、第19条第1項の交付にはなりません。初めての取引先や、消費者に当たる注文者との工事では、とくに確認してください。

---

## 代金と工期にも、別の禁止があります

記載事項とは別に、契約の中身自体が問題になる規定があります。

- 注文者は、取引上の地位を不当に利用して、通常必要と認められる原価に満たない請負代金で契約してはならない（第19条の3第1項）
- 建設業者も、省令で定める正当な理由がないのに、通常必要と認められる原価に満たない代金で契約してはならない（同条第2項）
- 注文者も建設業者も、通常必要と認められる期間に比べて著しく短い工期で契約してはならない（第19条の5）

書面に15項目が書いてあっても、代金や工期がその禁止に当たれば、記載とは別の問題です。

---

## 書いていないと、どうなるか

第19条に違反したこと自体を、罰金や過料とする規定は、建設業法第8章の罰則には置かれていません。

一方で、許可を受けた建設業者が法律の規定に違反した場合、許可行政庁は必要な指示をすることができます（第28条第1項）。指示に従わないときや、指示を受ける事態が情状特に重いときは、営業停止などの処分につながり得ます。

それとは別に、書面がないと、追加工事の代金や工期の延長をあとから証明しにくくなります。第19条は、紛争を防ぐための規定でもあります。

---

## まとめ

- 建設工事の請負契約は、着手前に、第19条第1項の事項を書面にして相互に交付する
- いまのガイドラインが整理しているのは15項目。以前の「14項目」や「瑕疵担保」という説明のままでは足りない
- 価格の変動について「変更しない」と書くのは、第19条第1項に合わない
- 内容を変えるときも、着手前に変更書面を交付する。下請契約も同じ
- 電子契約は相手方の承諾が必要。注文書・請書の署名を省略できるのは、ガイドラインの3要件を満たす場合

許可の申請書とは別に、現場で使う契約書を、いまの第19条に合わせて見直しておくと、追加工事のときにも同じ型で書面を出せます。
