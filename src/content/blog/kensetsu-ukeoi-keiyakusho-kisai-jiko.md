## はじめに

建設業の許可が下りたあとに、よく聞かれるのが「契約書は、何を書いておけばよいか」です。

建設工事の請負契約は、口約束では足りません。当事者は、対等な立場の合意で公正な契約を結び、信義に従って誠実に履行します（建設業法第18条）。そのために、契約を結ぶときには、法律が定める事項を**書面に記載し、署名または記名押印をして、相互に交付**しなければなりません（第19条第1項）。

災害時などでやむを得ない場合を除き、交付は**工事の着手前**です。施工の途中や、工事が終わってから書面を渡すのでは、第19条第1項に合いません。これは、許可が必要な規模の工事に限りません。軽微な建設工事の請負契約も対象です。

かつては「14項目」と説明されることが多くありました。いまの第19条第1項は、工事を施工しない日・時間帯などが加わり、番号も変わっています。国土交通省の「発注者・受注者間における建設業法令遵守ガイドライン」（令和8年1月・第8版）は、契約書面に書く事項として**15項目**を整理しています。

このガイドラインは、公共工事と民間工事の発注者と受注者の取引を対象にしています。個人が専ら自ら利用する住宅や施設を目的とする工事の取引は、原則として含みません。その工事でも、第19条の書面交付義務はあります。下請契約の行為事例は、「元請負人と下請負人間における建設業法令遵守ガイドライン」（令和8年1月・第12版）も参照します。

## 書面に書く15項目

次が、ガイドラインが挙げている事項です。条文の第16号は「その他国土交通省令で定める事項」です。2026年11月28日時点の建設業法施行規則には、この第16号で追加する事項を定める規定は見当たりません。国土交通省のガイドラインも、記載事項を15項目として整理しています。将来、省令で事項が追加されれば、その事項も契約書面に書きます。

| 号 | 書くこと | 補足 |
|---|---|---|
| 1 | 工事内容 | 「○○工事一式」だけでは足りない。責任施工の範囲と施工条件を具体的に |
| 2 | 請負代金の額 | |
| 3 | 工事着手の時期と工事完成の時期 | |
| 4 | 工事を施工しない日または時間帯の定めをするときは、その内容 | 定めをする場合 |
| 5 | 請負代金の全部または一部の前金払、または出来形部分に対する支払の定めをするときは、その時期と方法 | 定めをする場合 |
| 6 | 設計変更、着手の延期、工事の全部または一部の中止の申出があったときの、工期の変更、請負代金の変更、損害の負担と、その額の算定方法 | |
| 7 | 天災その他の不可抗力による工期の変更、損害の負担と、その額の算定方法 | |
| 8 | 価格等の変動または変更に基づく、工事内容の変更または請負代金の変更と、その額の算定方法 | 「変更しない」とは書けない |
| 9 | 工事で第三者が損害を受けたときの賠償金の負担 | |
| 10 | 注文者が資材を提供し、または建設機械などを貸すときは、その内容と方法 | 提供・貸与がある場合 |
| 11 | 注文者が工事の全部または一部の完成を確認するための検査の時期と方法、引渡しの時期 | 部分完成を含む |
| 12 | 工事完成後の請負代金の支払の時期と方法 | |
| 13 | 種類または品質が契約に適合しないときの責任、またはその履行のための保証保険などの定めをするときは、その内容 | 定めをする場合。旧来の「瑕疵担保」という整理ではない |
| 14 | 履行遅滞その他の債務不履行のときの遅延利息、違約金その他の損害金 | |
| 15 | 契約に関する紛争の解決方法 | |

第4号、第5号、第10号、第13号は、「その定めをするとき」に内容を書きます。定めをしないときも、「定めはない」と書いておくと、あとから「口頭で約束した」という争いになりにくくなります。

### 特に抜けやすいところ

**工事内容**は、いちばん曖昧になりやすい項目です。ガイドラインは、受注者の責任施工の範囲と施工条件を具体的に書き、「○○工事一式」という書き方は避ける、としています。

**価格等の変動**に関する定めは、単に記載すればよいわけではありません。書いてあっても「変更しない」「変更を認めない」と、協議を前提としない内容だと、価格の変動を受けて契約を変えるという法律の趣旨に沿わず、第19条第1項に違反するとガイドラインは説明しています。金額の算定は「協議して定める」とし、協議では変動の内容などを考慮する、という書き方が例示されています。価格が変動したときに必ず請負代金を変更しなければならない、という意味ではありません。変更について協議できる契約内容にしておくことが重要です。

**契約不適合**は、民法改正前の「瑕疵担保」という見出しのままのひな形が残っていることがあります。いまの第13号は、目的物の種類または品質が契約の内容に適合しない場合の責任です。古いひな形を使用する場合は、見出しを置き換えるだけでは足りません。現行法に合わせて、契約条項を見直してください。

## 追加・変更は、着手前にもう一度書面にする

請負代金や工期など、第19条第1項の事項に当たる内容を変えるときは、その変更の内容を書面に記載し、署名または記名押印をして、相互に交付します（第19条第2項）。

「あとで金額は相談」のまま追加工事に入る、という進め方は、この規定に合いません。変更の書面は、原則として、追加・変更の工事に着手する前に交付します。

工事の状況により、追加工事の全体数量などを着手前に確定できないことがあります。その場合、ガイドラインは、その都度すぐに変更契約を結ぶことが不合理なら、着手前に次の3点を書いた書面を取り交わし、内容が確定した時点で遅滞なく変更契約を結ぶ、としています。

- 追加工事として施工を依頼する具体的な作業内容
- その工事が契約変更の対象になることと、契約変更を行う時期
- 追加工事の契約単価

この事前の書面は、変更契約そのものの代わりではありません。金額が確定できないからといって、何も書面に残さず工事を進めることにはなりません。

工事着手後に工期の変更が必要になり、変更後の工期がすぐに確定できない場合も、同じ考え方です。ガイドラインは、工期の変更が契約変更の対象になることと、契約変更を行う時期を書いた書面を、変更が必要と認めた時点で取り交わし、工期が確定した時点で遅滞なく変更契約を結ぶ、としています。

変更の書面にも、変わった部分だけでなく、工期や代金の算定方法が読み取れるようにします。当初の契約書に算定方法が書いてあれば、変更書面はその方法に沿って金額と工期を書きます。

## 下請契約でも同じです

第19条は、発注者と元請の間だけのルールではありません。建設工事の請負契約の当事者すべてが対象です。元請が一次下請と結ぶ契約も、一次下請がさらに出す契約も、同じように書面が必要です。

下請代金の支払時期には、別に第24条の3以下のルールがあります。第19条の記載を満たしていても、下請代金の支払期日まで満たしているとは限りません。この記事は、契約書面に書く事項の説明です。

見積書は、作成、交付、考慮が分かれています。建設業者は、工事の種別に応じ、材料費、労務費、法定福利費などの必要経費の内訳と、工程ごとの作業およびその準備に必要な日数を記載した見積書を作成するよう努めなければなりません（第20条第1項、施行規則第13条の12）。注文者は、契約を締結する際に、その見積書の内容を考慮するよう努めます。注文者から請求があったときは、建設業者は、契約が成立するまでに見積書を交付しなければなりません（同条第4項）。

### 他の法律による追加の記載事項

建設業法第19条の記載事項だけで、すべての工事の契約書が十分になるとは限りません。

建設リサイクル法の対象建設工事では、同法第13条と、特定建設資材に係る分別解体等に関する省令第7条に基づき、次の事項も契約書面に記載します。

- 分別解体等の方法
- 解体工事に要する費用
- 再資源化等をするための施設の名称および所在地
- 再資源化等に要する費用

詳しくは[建設リサイクル法とは？分別解体・事前届出・完了報告の義務を解説](/blog/kensetsu-recycle-ho-bunbetsu-kaitai/)もご覧ください。

## 電子契約と、注文書・請書

書面の交付に代えて、相手方の承諾を得たうえで、電子情報処理組織その他の情報通信技術を使う方法ができます（第19条第3項）。電子でも、上の15項目の記載は必要です。

電子契約を使うときは、あらかじめ利用する電磁的措置の種類と内容を示し、書面または電磁的方法で相手方の承諾を得ます。承諾の手続は政令と省令にあり、相手方はあとから承諾を撤回できます。電子契約の方法自体も、建設業法施行規則第13条の4から第13条の6が定める要件を満たす必要があります。承諾があれば、どのような方法でもよいわけではありません。

国土交通省は、「電磁的措置による建設工事の請負契約の締結に係るガイドライン」（令和7年9月）を出しています。電子契約にするときは、こちらを参照します。

注文書と請書で契約する方法には、あらかじめ基本契約書を締結して個別の注文書・請書を交換する方法と、同じ内容の基本契約約款を添付した注文書・請書だけで契約する方法があります。いずれも、国土交通省の通知が定める記載事項や書面の交付方法などの要件を満たす必要があります（「注文書及び請書による契約の締結について」令和7年9月30日最終改定）。

基本契約書を締結する方式では、基本契約書に、個別の注文書・請書に書く事項以外の第19条第1項の事項を記載し、署名または記名押印をして相互に交付します。基本契約約款を添付する方式では、注文書と請書のそれぞれに同じ内容の約款を添付し、注文書または請書と基本契約約款が複数枚に及ぶ場合には、割印を押します。

注文書と請書には、工事内容、請負代金の額、工事着手の時期と工事完成の時期、施工しない日または時間帯の定め、その他必要な事項を書きます。それ以外の事項は、基本契約書または基本契約約款による旨を明記します。

このうち、基本契約書を締結したうえで個別の注文書・請書を交換する方法では、次の3つをすべて満たすときは、個別の注文書・請書への署名または記名押印を省略できます。約款を添付するだけの方式では、この省略は認められていません。省略しないときは、注文書には注文者が、請書には請負者が、それぞれ署名または記名押印をします。

- 注文者が、消費者契約法の「消費者」ではない
- 基本契約を結ぶときに、発注者・受注者間のガイドライン、または元請負人と下請負人のガイドラインの考え方に従い、対等なパートナーシップにあることを双方で確認している
- 基本契約を結ぶときに、双方の間に反復継続した取引の実績があることを確認している

署名または記名押印を省略できる場合でも、注文書を一方的に交付するだけでは足りません。請書との相互交付が必要です。初めての取引先や、消費者に当たる注文者との工事では、省略の要件にも注意してください。

## 代金と工期にも、別の禁止があります

記載事項とは別に、契約の中身自体が問題になる規定があります。令和7年12月12日施行の改正で、不当に低い請負代金と著しく短い工期については、注文者だけでなく、請け負う建設業者側にも禁止が置かれています。

- 注文者は、取引上の地位を不当に利用して、通常必要と認められる原価に満たない請負代金で契約してはならない（第19条の3第1項）
- 建設業者も、省令で定める正当な理由がないのに、通常必要と認められる原価に満たない代金で契約してはならない（同条第2項）
- 注文者も建設業者も、通常必要と認められる期間に比べて著しく短い工期で契約してはならない（第19条の5第1項・第2項）

書面に15項目が書いてあっても、代金や工期がその禁止に当たれば、記載とは別の問題です。

## 書いていないと、どうなるか

第19条に違反したこと自体を、罰金や過料とする規定は、建設業法第8章（第47条から第55条）には置かれていません。

一方で、許可を受けた建設業者がこの法律の規定に違反した場合、許可行政庁は必要な指示をすることができます（第28条第1項）。第19条は、同項が指示の対象から除いている規定には含まれていません。その指示に従わないときは、1年以内の期間を定めて、営業の全部または一部の停止を命ぜられることがあります（同条第3項）。

なお、契約書面がないことによって、直ちに民法上の請負契約が無効になるわけではありません。請負契約は、当事者の合意で成立します。契約が成立していることと、建設業法上の書面交付義務を満たしていることは、別の問題です。

それとは別に、書面がないと、追加工事の代金や工期の延長をあとから証明しにくくなります。第19条は、紛争を防ぐための規定でもあります。

## まとめ

- 建設工事の請負契約は、着手前に、第19条第1項の事項を書面に記載し、相互に交付する
- いまのガイドラインが整理しているのは15項目。第16号の省令事項は、2026年11月28日時点では定められていない。以前の「14項目」や「瑕疵担保」という説明のままでは足りない
- 価格の変動について「変更しない」と書くのは、第19条第1項に合わない。必ず増額する、という意味でもない
- 内容を変えるときも、原則は着手前の変更書面。数量や工期がすぐに確定しないときは、ガイドラインの事前書面を残し、確定後に遅滞なく変更契約を結ぶ。下請契約も同じ
- 電子契約は、承諾と、省令が定める方法の両方が必要。注文書・請書の署名を省略できるのは、基本契約書がある場合の3要件を満たすときで、請書との相互交付は必要

許可の申請書とは別に、現場で使う契約書を、いまの第19条に合わせて見直しておくと、追加工事のときにも同じ型で書面を出せます。
