## はじめに

解体工事業の登録を考えるとき、最初に詰まりやすいのが**技術管理者**です。

建設業許可の営業所技術者等（現場では専任技術者と呼ぶこともあります）と名前が似ていますが、根拠法も、求め方も別です。この記事では、登録のために選任する技術管理者の位置づけと、主な資格・実務経験、変わったときの届出を整理します。

土木工事業・建築工事業・解体工事業の建設業許可がある場合、解体工事業者登録自体が不要になることがあります。登録が要るかどうかは、[解体工事業者が整えるべき3つの手続き](/blog/kaitai-gyosha-3-tetsuzuki-set/)で先に確認してください。

---

## 技術管理者は何をする人か

解体工事業者は、工事現場における解体工事の施工の技術上の管理をつかさどる者で、主務省令の基準に合う人を**技術管理者**として選任しなければなりません（建設リサイクル法第31条）。選任していないと、登録を拒否されます（同法第24条第1項第8号）。

選任するだけではなく、請け負った解体工事を施工するときは、技術管理者に、その工事に従事する他の者の監督をさせなければなりません（同法第32条）。技術管理者以外の者がその工事に従事しない場合は、この監督の規定は適用されません。

営業所と解体工事の現場には、公衆の見やすい場所に標識を掲げます（同法第33条）。現場の標識には、その現場に置かれる技術管理者の氏名を記載する様式になっています。

技術管理者を選任しなかった場合は、建設リサイクル法第51条第3号により、20万円以下の罰金の対象となります。

## 建設業許可の営業所技術者等とは別です

| | 技術管理者 | 営業所技術者等 |
|---|---|---|
| 根拠 | 建設リサイクル法 | 建設業法 |
| 主な場面 | 解体工事業登録 | 建設業許可 |
| 置き方 | 基準に合う者を選任し、施工時に監督させる | 営業所ごとに、許可業種に応じた者を置く |

同じ資格でも、どちらの制度で使うかによって条件が異なります。例えば、2級土木施工管理技士（種別「土木」）は、解体工事業登録の技術管理者の資格要件に該当します。一方、建設業許可（解体工事業）の営業所技術者等では、資格の取得時期によって、追加の実務経験や登録解体工事講習が必要になる場合があります。

**では、同じ人が両方を兼務できるのでしょうか。**

まず、土木工事業・建築工事業・解体工事業の建設業許可を受けている場合は、解体工事業登録が不要となるため、登録上の技術管理者を別に選任する必要はありません。

一方、とび・土工工事業など、これら以外の建設業許可を受けている事業者が解体工事業登録を行う場合は、兼務の可否が問題になります。

大阪府の「解体工事業登録申請等の手引き」では、建設業許可業者に勤務する技術管理者は、常勤性を必要とする経営業務の管理責任者や営業所技術者等と兼務できないとされています。つまり、資格要件を満たしていても、これらの役職を務めている人を、そのまま技術管理者に選任することはできません。選任の際は、保有資格だけでなく、現在の役職や勤務状況も確認する必要があります。

なお、この記事で紹介する資格・実務経験の一覧は、解体工事業登録の技術管理者についての基準です。

## 技術管理者になれる基準（主な例）

基準は、解体工事業に係る登録等に関する省令で定められています。次は主な区分です。証明書の種類は、登録する都道府県の手引きで確認してください。

### 資格で選任する場合

資格の種別まで見ます。2級だからすべて認められる、ではありません。

建設業法に基づく技術検定については、第二次検定の合格が必要です。第一次検定のみの合格者（技士補）は、この資格要件には該当しません。省令の文言は、建設機械施工について「建設機械施工管理」です。資格証の名称は「建設機械施工技士」となっていることがあります。

| 区分 | 内容 |
|---|---|
| 建設機械施工技士 | 1級。2級は第1種または第2種 |
| 土木施工管理技士 | 1級。2級は種別「土木」 |
| 建築施工管理技士 | 1級。2級は種別「建築」または「躯体」 |
| 建築士 | 1級または2級 |
| 技術士 | 第二次試験の建設部門 |
| 技能検定 | 1級のとび、または1級のとび工。2級のとびまたはとび工は、合格後に解体工事の実務経験が1年以上 |
| 登録試験 | 公益社団法人全国解体工事業団体連合会の**解体工事施工技士** |

解体工事施工技士に、1級・2級の区分はありません。建設機械施工技士や施工管理技士の級とは別の資格です。省令改正前に国土交通大臣が指定した試験の合格者も、手引きで認められることがあります。

このほか、国土交通大臣がこれらの者と同等以上の知識と技能を有すると認定した者も、技術管理者の基準に含まれます（省令第7条第4号）。該当するかは、認定の内容を個別に確認します。

### 実務経験で選任する場合

一定の学科を修めて卒業しているかどうかで、必要な年数が変わります。学科は、土木工学（農業土木、鉱山土木、森林土木、砂防、治山、緑地または造園に関する学科を含む）、建築学、都市工学、衛生工学または交通工学です。いわゆる専門学校の卒業が、この学歴区分に入るとは限りません。

| 学歴 | 解体工事の実務経験 |
|---|---|
| 大学または高等専門学校で一定の学科を修めて卒業 | 2年以上 |
| 高等学校または中等教育学校で一定の学科を修めて卒業 | 4年以上 |
| 上記以外 | 8年以上 |

実務経験は、解体工事の施工を指揮・監督した経験や、施工に携わった経験です。見習い期間のうち技術的な経験は含まれることがあります。現場の単なる雑務や事務は含まれません。

### 講習で年数を短縮する場合

国土交通大臣の登録講習を修了すると、上の実務経験を1年短縮できる区分があります。公益社団法人全国解体工事業団体連合会の**解体工事施工技術講習**がこれに当たります。短縮後の目安は、大学・高専が1年以上、高校が3年以上、その他が7年以上です。

この講習の修了は、解体工事施工技士の試験合格とは別です。講習を受けただけでは、資格の欄の「解体工事施工技士」にはなりません。

### 実務経験を証明するときの注意

大阪府の手引きでは、平成13年12月以降の実務経験について、証明者がその期間に建設業許可業者（土木工事業、建築工事業、解体工事業）または解体工事業登録業者であることが必要です。とび・土工工事業の許可だけで証明できる期間には、経過措置の期限があります。

証明が取れない場合の自己証明を認めるかは、申請先の手引きによります。大阪府は、理由を明記した自己証明を受け付ける記載があります。

和歌山県でも、実務経験の証明者は原則として使用者とされ、証明期間中の解体工事業登録や対象となる建設業許可の有無が確認されます。事業の承継や倒産などにより自己証明しかできない場合は、申請時に相談するよう案内されています。

### 在籍の確認（大阪府）

大阪府では、資格や実務経験だけでなく、技術管理者が申請者に雇われていることも確認します。手引きでは、この確認を在籍の確認と呼んでいます。技術管理者が代表者本人の場合は、確認書類は不要です。

代表者以外のときは、次のいずれかを用意します。

- 技術管理者の健康保険被保険者標準報酬決定通知書（直近年のもの）の写しで、申請者が雇用主と分かること
- 技術管理者の雇用保険証の写しで、申請者が雇用主と分かること
- 給与の支払いが分かる直近3か月分の給与台帳の写し。申請の3か月以内に雇った場合は、雇用契約書の写しと、それ以降の給与台帳の写し

給与台帳で確認した場合、受付後に健康保険か雇用保険の書類を求められることがあります。新規・更新では提示、変更届を郵送するときは提出です。和歌山県の確認書類は、県の手引きで見てください。

## 変わったときの届出

登録申請書に記載する事項には、技術管理者の氏名が含まれます（建設リサイクル法第22条）。その事項に変更があったときは、**変更の日から30日以内**に、登録を受けた都道府県知事へ届け出ます（同法第25条）。

大阪府で技術管理者を変更する場合は、変更の日から30日以内に、正本・副本各1部を届け出ます。必要なのは、解体工事業登録事項変更届出書（規則様式第6号）、新たな技術管理者の資格要件を確認する書類、在籍を確認する書類です。窓口では在籍確認書類は提示、郵送では提出です。

変更届は、一般書留または簡易書留で郵送できます。副本返却用の封筒と切手を同封しないと受け付けません。必要書類や提出方法は、大阪府の最新の手引きで確認してください。

なお、代理人が変更届を提出する場合は、委任状の原本（副本は写し）が必要です。

### 和歌山県で技術管理者を変更する場合

和歌山県でも、技術管理者を変更した場合は、変更の日から30日以内に届出が必要です。

和歌山県の公式案内では、変更届出書（別記様式第6号）に加え、技術管理者の住民票抄本と、基準に適合することを証明する書面が必要とされています。

必要書類や提出方法については、和歌山県の最新の公式案内を確認してください。

大阪府と和歌山県の両方で登録している場合は、それぞれの登録について手続きが必要です。

技術管理者を欠いたまま工事を続けると、選任義務を満たさない状態になります。後任が基準に合うことを確認してから届け出てください。

## まとめ

- 技術管理者は、建設リサイクル法の解体工事業登録で選任する人です。建設業許可の営業所技術者等とは別です。
- 資格で足りる場合と、実務経験の年数で足りる場合があります。2級は種別、解体工事施工技士は級のない登録試験、講習は年数の短縮、と分けて見てください。
- 工事のときは、技術管理者に他の従事者を監督させます。
- 技術管理者が変わったら、変更の日から30日以内に、登録先の都道府県へ届け出ます。

現在の従業員が技術管理者の要件を満たしているかどうかは、保有資格の種類や実務経験の内容、証明できる資料などを確認して判断する必要があります。
