## はじめに

解体工事業の登録は、一度取れば終わりではありません。**5年ごとの更新**があり、登録した内容が変わったときは**30日以内の届出**が必要です。

更新を忘れて有効期間が過ぎると、登録は効力を失います。そのまま解体工事を請け負うと、無登録営業になります。

この記事では、解体工事業登録の更新と変更届、廃業等の届出、建設業許可を取ったときの通知を、大阪府・和歌山県の手引きに沿って整理します。登録の要否や新規登録の要件は、[解体工事業者が整えるべき3つの手続き](/blog/kaitai-gyosha-3-tetsuzuki-set/)と[解体工事業の技術管理者とは？](/blog/kaitai-gijutsu-kanrisha-shikaku-yoken/)で説明しています。

---

## 登録の有効期間は5年です

解体工事業の登録は、5年ごとに更新を受けなければ、期間の経過によって効力を失います（建設リサイクル法第21条第2項）。

更新を受けようとするときは、**有効期間満了の日の30日前まで**に更新を申請しなければなりません（解体工事業に係る登録等に関する省令第2条）。これは、申請の期限です。

これとは別に、更新の申請があったのに、満了日までにその処分がされないときは、処分がされるまでの間、従前の登録はなお有効です（法第21条第3項）。この場合に更新がされると、新しい有効期間は、**従前の満了日の翌日**から起算します（同条第4項）。審査が満了日を過ぎても、その分だけ次の満了日が後ろにずれるわけではありません。

| 項目 | 内容 |
|---|---|
| 有効期間 | 5年（法第21条第2項） |
| 更新申請の期限 | 有効期間満了の日の30日前まで（省令第2条） |
| 受付の開始（大阪府） | 有効期間満了の日の3か月前から |
| 満了日までに処分がされなかったとき | 処分まで従前の登録は有効。更新後の起算日は従前の満了日の翌日（法第21条第3項・第4項） |

### 更新を忘れて期限が過ぎたら

有効期間が満了すると、登録は効力を失います。引き続き解体工事業を営むには、**新規で登録を受け直す**ことになります。

登録が効力を失う前に締結した請負契約については、その工事を完成する目的の範囲内で施工を続けることができます（法第29条第1項・第3項）。ただし、都道府県知事から施工の差止めを命じられる場合があります（同条第2項）。登録が効力を失ったあとは、遅滞なく、その旨をその工事の注文者に通知しなければなりません（同条第1項）。この通知を怠ると、**20万円以下の罰金**の対象です（法第51条第2号）。

注文者は、その通知を受けた日、または登録が効力を失ったことを知った日から**30日以内**に限り、契約を解除できます（同条第4項）。新しい工事の受注は、登録を受け直すまでできません。登録を受けないで解体工事業を営むと、**1年以下の拘禁刑または50万円以下の罰金**の対象です（法第48条第1号）。

## 更新申請の手続き（大阪府）

大阪府の更新申請は、新規と同じ手引きで案内されています。

| 項目 | 大阪府の取扱い |
|---|---|
| 申請先 | 建築振興課 申請会場（咲洲庁舎1階） |
| 提出方法 | 窓口のみ。郵送では受け付けていません |
| 手数料 | 26,000円（新規は33,000円） |
| 部数 | 正本・副本 各1部 |
| 通知までの目安 | 受理し、補正などが解消された日から、土日・祝日を含む4週間程度で発送 |

4週間程度という目安には、年末年始の閉庁日（12月29日〜1月3日）と大型連休は含まれません。通知が届くまでの余裕を見て、早めに申請してください。

更新申請に必要な書類は、新規とほぼ同じです。登録申請書（規則様式第1号）、誓約書（規則様式第2号）、技術管理者の資格要件を確認する書類、登録申請者の調書（規則様式第4号）、商業登記簿謄本または住民票などを提出します。

更新ならではの書類として、**解体工事業登録通知書の原本または写し**を窓口で提示します。営業所の所在地を確認する書類、本人確認書類の提示も、新規と同じように求められます。

### 技術管理者は更新のときも確認されます

更新は、5年前と同じ内容を出し直す手続きではありません。更新申請でも、技術管理者の資格要件を確認する書類が必要です。技術管理者の在籍確認書類も求められますが、技術管理者が代表者の場合は不要です。

5年の間に技術管理者が退職・交代していた場合は、変更届を出しているかを確認してください。大阪府の手引きでは、受付のときに技術管理者の要件が確認できない場合は、受け付けられないとされています。

## 更新申請の手続き（和歌山県）

和歌山県でも、更新は有効期間満了の30日前までに申請します。

| 項目 | 和歌山県の取扱い |
|---|---|
| 申請先（県内に営業所がある場合） | 営業所の所在地を管轄する振興局建設部（海南市・海草郡は海南工事事務所）へ3部 |
| 申請先（県外に営業所がある場合） | 県庁の技術調査課へ2部 |
| 提出方法 | 窓口または郵送（切手を貼った返信用封筒を同封） |
| 手数料 | 26,000円分の和歌山県証紙（新規は33,000円分） |

県外に営業所がある事業者、たとえば泉州に本店がある事業者が和歌山県の登録を更新する場合は、県庁の技術調査課が申請先です。

---

## 大阪府と和歌山県の両方で登録している場合

解体工事業の登録は、工事を行う区域を管轄する都道府県知事ごとに受けます（法第21条第1項）。たとえば、泉州を拠点として大阪府内と和歌山県内の両方で解体工事を行う事業者は、土木工事業・建築工事業・解体工事業の許可を受けている場合を除き、大阪府と和歌山県のそれぞれで登録が必要です。

それぞれの登録は別の手続きです。有効期間の満了日も、登録ごとに違います。片方を更新しても、もう片方は更新されません。

大阪府の更新受付は、満了日の3か月前から始まります。和歌山県の受付開始日は、県の案内で確認してください。いずれの県でも、申請の期限は満了日の30日前です。

## 変更届は30日以内に

解体工事業者は、登録申請書に書いた事項に変更があったときは、**変更の日から30日以内**に、登録を受けた都道府県知事に届け出なければなりません（法第25条第1項）。

届出の対象は、登録申請書の記載事項です（法第22条第1項）。

- 商号・名称・氏名と住所
- 営業所の名称と所在地
- 法人の役員（相談役・顧問なども含みます）
- 未成年者の場合の法定代理人
- 技術管理者

### 大阪府で必要になる主な添付書類

大阪府では、変更届は窓口のほか、一般書留または簡易書留での郵送もできます。郵送のときは、副本返却用の封筒と返信用の切手を必ず同封します。同封がないと受け付けてもらえません。

| 変更した事項 | 解体工事業登録事項変更届出書（規則様式第6号）に添える主な書類 |
|---|---|
| 商号・名称 | 発行後3か月以内の商業登記簿謄本（法人） |
| 営業所の所在地・個人の住所 | 商業登記簿謄本（法人）または住民票（個人）。登記上の所在地以外を主たる営業所とする場合は、賃貸契約書の写しなど |
| 営業所の名称 | 商業登記簿謄本（登記に変更がない場合は不要） |
| 役員 | 誓約書、登録申請者の調書、商業登記簿謄本。退任だけのときは誓約書と調書は不要 |
| 技術管理者 | 新しい技術管理者の資格要件を確認する書類と、在籍を確認する書類 |

技術管理者の在籍確認書類は、窓口では提示、郵送では提出です。代理人が届け出る場合は、委任状の原本（副本は写し）も必要です。

### 和歌山県で必要になる主な添付書類

和歌山県の公式案内では、変更届出書（別記様式第6号）に、次の書類を添えるとされています。

| 変更した事項 | 添付書類 |
|---|---|
| 氏名・住所など、登記の変更を伴わないもの | 住民票抄本 |
| 営業所の名称・所在地など、登記の変更を伴うもの | 登記事項証明書 |
| 法人の役員 | 登記事項証明書、新たに役員になった人の住民票抄本、誓約書、登録申請者の調書 |
| 未成年者の法定代理人 | 住民票抄本、誓約書、登録申請者の調書 |
| 技術管理者 | 住民票抄本、基準に適合することを証明する書面 |

### 届出を忘れたときのリスク

変更届を出さなかったり、虚偽の届出をしたりすると、**30万円以下の罰金**の対象です（法第50条第2号）。登録の取消し、または六月以内の事業の全部もしくは一部の停止の対象にもなり得ます（法第35条第1項第3号）。

特に忘れやすいのは、役員の就任・退任と、技術管理者の交代です。新しい取締役が就任した場合や、登録している技術管理者が交代した場合は、変更届が必要です。

技術管理者が交代すると、営業所に掲げる登録票（標識）の「技術管理者の氏名」も変わります。現場の登録票には、その現場に置く技術管理者の氏名を書きます（法第33条、省令第8条）。届出とあわせて、登録票も書き換えてください。

## 廃業等の届出も30日以内

次の場合は、その日から30日以内に、定められた人が届け出ます（法第27条第1項）。届出の事由が生じたときに、登録は効力を失います（同条第2項）。

| 届出の事由 | 届け出る人 |
|---|---|
| 個人の解体工事業者が死亡した | 相続人 |
| 法人が合併で消滅した | その法人を代表する役員であった人 |
| 法人が破産手続開始の決定で解散した | 破産管財人 |
| 法人が合併・破産以外の理由で解散した | 清算人 |
| 登録した都道府県の区域で解体工事業をやめた | 個人の本人、または法人を代表する役員 |

この届出を怠ると、10万円以下の過料の対象です（法第53条第2号）。

和歌山県の案内では、解体工事業者が死亡し、相続人が営業を続ける場合、その相続人は**新たに登録を受けなければならない**とされています。個人事業の登録は、相続人に引き継がれません。

死亡などで登録が効力を失ったあとも、効力を失う前に結んだ請負契約の工事は、相続人などの一般承継人が、その工事を完成する範囲で施工できます（法第29条）。新しい契約を結んで営業を続けるには、改めて登録が必要です。

## 建設業許可（土木・建築・解体）を取ったら

解体工事業の登録を受けた後に、建設業法の**土木工事業・建築工事業・解体工事業**のいずれかの許可を受けると、解体工事業の登録は効力を失います（法第21条第5項）。この3業種の許可があれば、登録がなくても解体工事業を営めるからです。

この場合は、許可を受けた旨を、登録を受けている都道府県知事に通知します（省令第1条）。省令には、提出期限の定めはありません。大阪府は、建設業許可取得通知書に許可通知書の写し（または許可証明書）を添えて、許可後30日以内に提出するよう求めています。和歌山県にも参考様式があります。

大阪府と和歌山県の両方で登録していた場合は、それぞれに通知します。

### 3業種以外の許可を取った場合

大工工事業、管工事業、とび・土工工事業など、**3業種以外の許可**を取っても、解体工事業の登録は失効しません。通知も不要です。引き続き解体工事業を営むなら、登録の更新が必要です。

このとき注意したいのが、技術管理者の兼務です。大阪府の手引きでは、建設業許可業者に勤務する技術管理者は、常勤性を必要とする経営業務の管理責任者や営業所技術者等と兼務できないとされています。許可を取ったことで、同じ人に役割が重なっていないか確認してください。

## 更新・届出を忘れないための管理

- 登録している都道府県ごとに、登録番号と有効期間の満了日を一覧にする
- 満了日の3か月前に、更新の準備を始める。技術管理者の在籍と資格を、このとき確認する
- 役員の就任・退任、本店の移転、技術管理者の交代があったら、その日から30日以内に届け出る
- 建設業許可も持っている場合は、許可の更新・変更届の期限と混同しない。建設業許可の変更届は、事項によって2週間以内のものがあります

建設業許可の変更届の期限は、[建設業許可の変更届とは？2週間・30日の期限と出し忘れの注意点](/blog/henko-todoke-kigen-guide/)で整理しています。

## まとめ

- 解体工事業登録の有効期間は5年。満了日の30日前までに更新を申請する
- 大阪府は満了日の3か月前から受付。新規・更新は窓口提出のみで、手数料は26,000円
- 和歌山県の更新手数料は26,000円分の県証紙。県外に営業所がある場合は県庁の技術調査課へ
- 登録事項が変わったら30日以内に変更届。技術管理者の交代は、資格と在籍の確認書類が必要
- 土木・建築・解体の建設業許可を取ると、登録は失効し、登録先へ通知する

大阪府と和歌山県の両方で登録している場合は、満了日や届出先がそれぞれ違います。現在の登録内容を一度整理しておくと、更新の時期に慌てずに済みます。
