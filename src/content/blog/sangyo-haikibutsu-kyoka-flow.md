## はじめに

「産廃の許可を取りたいけど、何から手をつければいいのかわからない」

建設・解体工事に携わる事業者が、産業廃棄物収集運搬業許可（以下、産廃許可）の取得を検討し始めたときに、よく出てくる疑問です。

産廃許可は申請書を出すだけでは取得できません。**講習の受講、書類準備、申請、審査**という一連のステップがあり、許可取得までの期間は実務上おおむね**2〜4か月が目安**です。これは公式の保証期間ではなく、講習会の予約状況、書類の準備状況、補正の有無によって前後します。

この記事では、産業廃棄物収集運搬業（積替え・保管を含まない）の**新規許可**を取るまでのフローを、大阪府・和歌山県の最新の手引きをもとに整理します。更新・変更許可は、修了証の取扱いなどが異なります。

### 先に確認しておきたいこと：許可が必要になる場合

建設工事で発生した産業廃棄物は、原則として**元請業者が排出事業者**です。元請業者が自ら運搬する場合は、通常、産業廃棄物収集運搬業の許可は必要ありません。一方、**他社から委託を受けて産業廃棄物を収集運搬する場合**は、原則として許可が必要です。

許可が必要になる場合、積込み場所と荷下ろし場所のそれぞれを管轄する都道府県知事等の許可が必要です。大阪府泉州エリアで積み、和歌山県内で下ろすなら、原則として大阪府知事と和歌山県知事の両方の許可が必要です。詳しくは[大阪府と和歌山県をまたいで廃棄物を運ぶなら産廃許可はいくつ必要か](/blog/sangyo-haikibutsu-osaka-wakayama-ryoken/)もご覧ください。

## 全体の流れと所要期間の目安

```
STEP 1  JWセンターの講習受講・修了証取得
STEP 2  申請書類の準備
STEP 3  申請窓口への提出・手数料納付
STEP 4  審査
STEP 5  許可証の受領・車両表示
```

| フェーズ | 目安 |
|---|---|
| 講習申込〜修了証到着 | 予約状況による。合格後、試験日から約3週間で修了証が届く |
| 書類準備 | 2〜4週間 |
| 大阪府の審査 | 標準処理期間60日（補正に要する期間は含まない） |
| 和歌山県の審査 | 標準処理期間42日（土日祝除く。電子申請は添付書類到着後から起算） |

標準処理期間は、各行政庁が定める審査の目安です。必ずその日数で許可が出るとは限りません。

## STEP 1 ｜ JWセンターの講習を受講する

### 講習修了の位置づけ

産業廃棄物収集運搬業の許可を受けるには、事業を的確に行うために必要な知識・技能を備えていることが求められます（廃棄物処理法第14条第5項、同施行規則第10条）。その確認資料として、**公益財団法人日本産業廃棄物処理振興センター（JWセンター）**などが実施する講習会の修了証が用いられます。

### 講習を受講する人

講習会は、従業員なら誰でもよいわけではありません。大阪府・和歌山県の手引きでは、おおむね次のとおりです。

- **法人の場合**：代表者、役員または政令で定める使用人
- **個人事業主の場合**：申請者本人または政令で定める使用人

政令で定める使用人は、本店・支店の代表者や、契約締結権限を持つ者を置く事業場の代表者など、法令上の要件を満たす者に限られます。役員の範囲は申請先の手引きで表現が異なります。和歌山県の手引きには「その業務を行う役員（監査役を含む。）」との記載がありますが、監査役であれば当然に受講できるという意味ではありません。監査役を受講者とする場合は、申請先に確認してください。

### 講習修了証は申請前に必要？

**本記事で扱う新規許可申請**では、申請先によって取扱いが異なります。

大阪府では、新規許可申請時に有効な講習修了証の添付が必要で、修了証がなければ申請を受け付けないとされています。更新・変更許可申請については、一定の条件で受講票の写し等と誓約書による対応も示されています。

一方、和歌山県では、申請時に修了証を添付できない場合、申立書と講習会の申込みが完了したことを証する書類（受講票またはJWセンターからの受講決定メールの写しなど）を提出する取扱いがあります。ただし、申請の日から起算して3か月を経過する日までに修了証を提出できない場合は、不許可となる可能性があります。

いずれの場合も、講習会の予約状況によって許可取得時期が左右されるため、早めに受講を済ませておくことをおすすめします。

### 受講する講習の種類

建設・解体現場の廃棄物を運ぶ場合に必要なのは、原則として**産業廃棄物の収集・運搬課程（新規）**です。

処分業や特別管理産業廃棄物（廃石綿・廃水銀等）の収集運搬を行う場合は、それぞれ別の課程が必要です。

新規申請でも、更新講習の修了証を利用できる場合があります。和歌山県では、すでに他の都道府県等で産廃収集運搬業の許可を受けている場合、本県で過去1年以内に許可を得ていた場合、個人事業主の法人化に伴う申請の場合など、一定の条件で更新講習の修了証を新規申請に利用できます。大阪府では、新規申請に更新講習の修了証を用いる場合、それ単独では足りず、廃棄物管理士講習会の修了証と安全衛生管理規程等の写しを組み合わせる取扱いです。初めて許可を取る建設業者は、新規講習を受講するのが通常です。

### 修了証の有効期間と注意点

大阪府・和歌山県の手引きでは、おおむね次のとおりです。起算日の表現は申請先で異なるため、申請前に確認してください。

| 申請の種類 | 修了証の有効条件（大阪府・和歌山県） |
|---|---|
| 新規申請 | 申請時点から修了日が**過去5年以内** |
| 更新申請 | 現行許可の有効期限満了日から**過去5年以内**（優良認定業者は7年以内） |

講習修了証は、各自治体が定める有効期間や申請条件を満たしていれば、**複数の自治体への許可申請に利用できます**。大阪府と和歌山県でそれぞれ許可を取得する場合も、原則として講習を受け直す必要はありません。申請先によって修了証の取扱いや必要な添付書類（写しの提出など）が異なるため、事前に確認しましょう。

なお、大阪府の手引きでは、更新申請について「前回の新規又は更新許可申請時に提出した修了証は使用できません」とされています。同じ自治体での更新では、有効期間内でも新たに修了証を用意する必要があるのが原則です。

## 申請前に確認しておきたい許可要件

産業廃棄物収集運搬業の許可を取得するには、講習会の修了だけでなく、施設・申請者の能力・欠格要件などが審査されます（廃棄物処理法第14条第5項、同施行規則第10条）。実務上は、次の点を申請前に確認します。

- **運搬施設**：取り扱う産業廃棄物に適した車両や運搬容器等を確保しているか
- **経理的基礎**：事業を的確かつ継続して行うための経理的基礎があるか
- **欠格要件**：申請者や役員等が法令上の欠格要件に該当していないか
- **事業計画**：収集運搬する廃棄物の種類や運搬先など、事業計画が適切か

特に、直近の決算が赤字の場合や債務超過の場合には、申請先によって追加資料が必要になることがあります。和歌山県では、直前の事業年度で債務超過がある法人、または過去3年間の経常損益の平均が0円以下の法人について、事業改善計画書の添付が定められています。大阪府では、債務超過の場合に経理的基礎に関する申立書などの追加資料を求め、事前相談を案内しています。申請前に最新の手引きで確認しましょう。

## STEP 2 ｜ 申請書類を準備する

### 法人の場合の必要書類（基本一覧）

以下は**大阪府の法人申請を中心とした主な必要書類**です。申請者の状況、先行許可制度の利用、申請先によって必要書類や省略できる書類は異なります。実際の申請では、各自治体の最新チェックシートを確認してください。

| 分類 | 書類 |
|---|---|
| 申請書 | 許可申請書（様式第六号） |
| 事業計画書 | 事業計画の概要（様式第六号の二。第1面・第2面・第4面〜第8面、第10面。個人の場合は第9面も） |
| 講習修了証 | JWセンターの修了証の**写し**（大阪府の新規は必須） |
| 法人関係 | 履歴事項全部証明書（発行3か月以内） |
| 法人関係 | 定款の写し |
| 役員等 | 役員のほか、該当する株主（出資額5％以上）・政令使用人等の住民票（発行3か月以内） |
| 役員等 | 登記されていないことの証明書（成年後見登記） |
| 役員等 | 誓約書（様式第六号の二第10面） |
| 財務関係 | 貸借対照表・損益計算書・株主資本等変動計算書・個別注記表（**直前3年分**。個別注記表は未作成の場合は不要） |
| 税務関係 | 法人税の確定申告書の写し（別表一（一）・別表四、**直前3年分**） |
| 納税証明書 | 法人税の納税証明書（その1）、**直前3年分** |
| 車両 | **自動車検査証記録事項**の写し（電子化対応） |
| 車両 | 車両写真（申請先の様式に従う） |
| その他 | 事務所・駐車場の付近見取図、車両の使用関係に応じた書類 など |

大阪府では、先行許可制度を利用する場合に、住民票や登記されていないことの証明書を省略できることがあります。駐車場の使用権限を証明する書類は一律必須ではなく、車両の使用関係や申請先によって確認します。

### 和歌山県に申請する場合の追加確認書類

大阪府の基本一覧だけでは把握しにくい、和歌山県の手引きに記載された書類です。

- **搬入先業者の処分業許可証の写し**（和歌山県知事が交付したものを除く）
- **産業廃棄物の越境移動に関する指導要綱に係る誓約書**
- **事業計画の実施に必要な他の都道府県（市）の産業廃棄物収集運搬業許可の写し**（積替え・保管を県外で行う場合など、申請内容に応じて必要）
- 和歌山市長から積替え・保管を含む収集運搬業の許可を取得している場合は、その許可証の写し

和歌山県の新規申請では、搬入先の処分業許可証の写しと越境移動の誓約書の添付が求められます。他自治体の許可証の写しは、積替え・保管の有無など申請内容に応じて必要です。最新の手引きで確認してください。

### 【重要】車検証の電子化対応（令和5年1月以降）

令和5年1月4日から自動車検査証が電子化されました。申請の際は次のいずれかを提出します。

- **「自動車検査証記録事項」の写し**（国土交通省の正式名称。大阪府の案内では「自動車検査記録事項」と略記されることがあります）
- 電子車検証を専用アプリで読み取った情報を出力したもの

従来の紙の車検証をお持ちの場合は、有効期間内であれば引き続き使用できます。

### 事業計画書（様式第六号の二）の各面について

事業計画書は複数の面（書類）で構成されています。

| 面 | 内容 |
|---|---|
| 第1面 | 事業計画の概要 |
| 第2面 | 運搬施設の概要（車両一覧） |
| 第4面 | 収集運搬業務の具体的な計画 |
| 第5面 | 環境保全措置の概要 |
| 第6面 | 運搬車両の写真 |
| 第7面 | 運搬容器等の写真 |
| 第8面 | 事業の開始に要する資金の総額及びその資金の調達方法 |
| 第9面 | 資産に関する調書（個人の場合） |
| 第10面 | 誓約書 |

各面の様式は、申請先の公式サイトから無料でダウンロードできます。

### 車両写真の撮り方（申請先で異なる）

車両写真は、大阪府と和歌山県で一律ではありません。**申請先の様式に従ってください。**

- **大阪府**：1車両につき、全体が写っている**正面と片側面**が基本です。正面写真ではナンバープレートの文字が読めることが求められます。すでに許可を有している場合は、側面写真で所定の車体表示が確認できることが必要です。
- **和歌山県**：1車両につき、**正面写真と側面写真を1枚ずつ**添付します。車両表示は両側面に必要です。表示の文字が読み取れない場合は、表示部分を拡大した写真も添付します。

すでに他の自治体で許可番号を持っている場合は、申請時の写真に所定の車両表示を入れます。初めて許可を取る場合は、許可番号がまだないため、表示のない写真を添付し、許可番号の通知後に表示入りの写真を提出する取扱いです（和歌山県の手引き。大阪府でも、既に許可を有する場合の表示入り写真が求められます）。

### 大阪府独自の確認事項

大阪府では、申請書の内容を説明できる申請者または代理人が窓口に来庁する必要があります。「内容を説明できない場合は受付できない」（大阪府の手引きより）とされており、**行政書士に依頼する場合は委任状を忘れずに**用意します。

### 和歌山県の窓口

申請者の本店所在地によって窓口が分かれます。泉州など**県外の事業者**、および**和歌山市**に本店がある場合は、県庁の循環型社会推進課です。県内（和歌山市を除く）に本店がある場合は、所在地を管轄する保健所への持参申請になります。

**和歌山県環境生活部環境政策局 循環型社会推進課**（本店所在地が県外または和歌山市の場合）

- **来庁予約**：県外または和歌山市に本店所在地がある事業者が、県庁循環型社会推進課の窓口で申請する場合は、原則として事前予約が必要です（和歌山県のホームページから予約）。電子申請なら来庁予約は不要です。和歌山市以外の県内事業者は管轄の県立保健所等に申請します。来庁前に各窓口の受付方法を確認してください
- **県庁窓口の受付時間**：午前9時30分〜11時、午後1時30分〜4時（県立保健所等の受付方法は各窓口に確認）
- 提出部数：県外および和歌山市は**1部**、県内（和歌山市を除く）は正本1部・副本1部
- **電子申請対応（令和8年11月〜）**：県外または和歌山市に本店所在地がある事業者が対象。申請書第1〜4面を送信し、クレジットカードまたはPayPayで手数料を納付できます。電子申請日が申請受付日となります。添付書類は電子申請後1週間以内に郵送します。標準処理期間は添付書類到着後42日（土日祝除く）です

| 許可の種類 | 新規 | 更新 | 変更 |
|---|---|---|---|
| 産業廃棄物収集運搬業 | **81,000円** | 73,000円 | 71,000円 |
| 特別管理産廃収集運搬業 | 81,000円 | 74,000円 | 72,000円 |

### 大阪・和歌山の両方に申請する場合

大阪府と和歌山県の両方に申請する場合、**それぞれの自治体で申請書類を準備する必要があります**。講習修了証など共通して利用できる資料もありますが、原本・写しの取扱いや省略できる書類は申請先ごとに確認が必要です。

和歌山県の「同時申請による重複書類省略」は、**同一の申請先に複数の申請書を同時に提出する場合**の取扱いです。大阪府と和歌山県という別々の行政庁をまたいで、原本を片方だけに出せば足りる、という意味ではありません。大阪府の手引きでも、重複書類の省略は「1つの行政庁に対し同時に2つ以上提出する場合」とされています。

準備そのものは並行して進められます。講習や証明書の取得を一度で済ませ、各窓口用の申請書を同時に整えると、取得までの期間を短くしやすくなります。

## STEP 4 ｜ 審査を受ける

審査期間の目安：

| 申請先 | 標準処理期間 |
|---|---|
| 大阪府 | **60日** |
| 和歌山県 | **42日（土日祝除く）** |

審査中に書類の補正（修正・追加）を求められることがあります。連絡があり次第速やかに対応することが遅延防止につながります。大阪府では、申請書の不備を補正するための期間は標準処理期間に含まれないとされています。

許可の審査期間中に、建設業許可の更新・経審・入札参加資格の更新など他の手続きと並行して進めることも可能です。

## STEP 5 ｜ 許可証を受領し、車両に表示する

許可取得後、産業廃棄物の収集運搬を開始するまでに、使用する車両に法定表示を行う必要があります。許可番号は許可後に付与されるため、初めて許可を取る場合は、申請時点では所定の番号表示ができません。

和歌山県では、新たに許可番号が付与される場合、許可証受領後に車両表示を行い、表示した車両の写真を提出する取扱いです。電子申請の場合は、許可証受領後に表示した写真をメール等で返送します。すでに他の都道府県等で許可番号を持っている場合は、申請時の写真に車両表示を入れておきます。

### 車両表示の義務（廃棄物処理法施行規則第7条の2の2）

産業廃棄物収集運搬業者は、収集運搬に使用する車両の**両側面**に、次の事項を表示しなければなりません。

- 産業廃棄物収集運搬車である旨（日本産業規格Z8305の140ポイント以上）
- 氏名または名称（同90ポイント以上）
- 許可番号（下6桁。同90ポイント以上）

識別しやすい色の文字で、鮮明に表示します。運搬時には、許可証の写しとマニフェスト（電子マニフェストの場合は加入証等）の携帯も必要です。表示の実務上の注意点は、[産廃収集運搬車両の表示義務と書類携帯義務](/blog/sangyo-haikibutsu-sharyo-hyoji-yoken/)でも整理しています。

### マニフェスト（産業廃棄物管理票）の準備

産業廃棄物の処理を他の事業者に委託する場合、原則として**排出事業者がマニフェストを交付**します。収集運搬業者は、マニフェストの受領・必要事項の記載・回付など、法令に定められた対応を行う必要があります。紙マニフェストのほか、電子マニフェスト（JWNET）を利用する方法もあります。

## 許可取得後の維持管理

### 許可の有効期間

- 通常：**5年**
- 優良産廃処理業者認定：**7年**

### 更新申請のタイミング

大阪府・和歌山県では、有効期限の**3か月前**から更新申請の受付が始まります。他の都道府県では異なる場合があるため、全国一律ではありません。

有効期限までに更新申請を行わなかった場合、許可は失効し、改めて新規申請が必要になります。一方、**有効期限内に更新申請が受理され、期限までに処分がなされない場合は、処分があるまで従前の許可が引き続き有効**となります。

更新時にも新たな講習修了証が必要になるのが原則です。更新申請の準備と並行して、次の講習日程を押さえておきましょう。

### 変更が生じた場合

車両の増減・役員変更・所在地変更などは、変更の日から**原則10日以内**に変更届が必要です。法人で登記事項証明書の提出が必要な場合は、**30日以内**です。

## まとめ

産業廃棄物収集運搬業許可（積替え・保管なし）の新規許可取得までの流れをまとめます。

1. **受講資格のある者**がJWセンターの講習を受講し、修了証を取得する（大阪府の新規は申請時に修了証が必要。和歌山県は申立書による例外あり）
2. 修了証を含む**申請書類**を、申請先の手引きに従って準備する
3. 大阪府（産業廃棄物指導課）または和歌山県（循環型社会推進課等）の**窓口に提出・手数料納付**
4. 大阪府60日・和歌山県42日の**審査**を待つ
5. 許可証受領後、**車両表示**とマニフェストへの対応を行う

大阪府・和歌山県どちらの許可も**新規申請手数料は81,000円**です。両府県で許可を取る場合、講習修了証は有効期間内であれば原則として使い回せますが、申請書類はそれぞれの窓口用に整える必要があります。
