やちよ行政書士事務所 ロゴ素材の見方
================================

■ パターン（01 / 02 / 03）
  01 … シンボル（マーク）のみ
  02 … シンボル ＋ 事務所名
  03 … 完全版（シンボル ＋ 事務所名 ＋ キャッチコピー）

■ 背景の種類（ファイル名の後半）
  透過_中白あり
    → 背景は透明。ロゴ内の白い部分（下の白い面）は残す。
    → Webサイト・色付き背景の上でも形が安定しやすい。
    → ※サイトのヘッダー／faviconは現在これを使用。

  透過_くり抜き
    → 背景も、ロゴ内の白い部分も透明。
    → 名刺などで下地の色・紙色を見せたいとき向け。

  白背景
    → 背景が真っ白（透過なし）。
    → Googleプロフィールなど、透過PNGが苦手／白背景の方がきれいな場所向け。

■ おすすめの使い分け（目安）
  Googleプロフ・白地のプロフィール画像 … 「白背景」
  色付き背景のWeb・アイコン … 「透過_中白あり」
  名刺で紙色を活かしたい … 「透過_くり抜き」
