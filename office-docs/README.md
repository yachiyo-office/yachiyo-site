## 使い方

1. HTMLをブラウザで開く
2. 薄い枠をクリックして編集
3. 「印刷 / PDF保存」

## 標準的な案件の流れと使う書式

1. 一次ヒアリング → 必要なら要件調査契約
2. 見積書 → **欠格要件・誠実性 確認書（自己申告）** → 業務委託契約 → **着手金請求・入金・領収書**
3. **初回案内メール**と**お客様用の必要書類一覧**（振込案内つき）
4. 資料収集（預り証）・社内チェックリスト進行
5. 申請前：**残金請求・入金** → 委任状 → 申請
6. 許可後：完了報告・**書類返却証**

産廃収集運搬・解体工事業登録も、見積・契約・請求・預り証・返却証・完了報告は件名を書き換えて使う。初回案内、必要書類一覧、欠格確認書は業務ごとのファイルを使う。委任状は申請先の指定様式を使う。

## 料金・支払いの基本方針

- 対外書類は時間単価ではなく項目加算
- 着手金＝報酬税込の半額。通常の交通費・駐車場代・郵送費は報酬に含む
- 申請前に、報酬の残り50％＋申請手数料＋証明書取得費用の見込額。証明書は終了後に実支出で精算
- 遠方出張・依頼者希望の追加訪問は、事前合意のうえ別途
- 契約前の訪問相談は一律2,000円（税込・駐車場代含む）。正式受任時は報酬へ充当し、重ねて請求しない
- 講習受講料はお客様が実施者へ直接支払う
- 申請先が複数のときは、見積書で申請先ごとに報酬を分ける

## グレーゾーン案件

許可の見込みが不透明な場合は、本申請の前に要件調査契約（税込33,000〜55,000円目安）を使う。  
申請見送りでも調査費用は返還しない旨を事前説明すること。

## 注意

- 金額の自動計算はしない
- 委任状は行政庁指定様式がある場合はそちらを優先。産廃・解体の委任状は自作していない
- 必要書類一覧は、お渡し前に申請先の最新手引きと突き合わせる。解体は大阪府手引き（令和8年3月）が基準。産廃の財務書類の年数は大阪府・法人の新規の例
- 本雛形は一般的な業務用ドラフトです。必要に応じて調整してください
- 市販の書式セットが必要になったら購入検討でよい（全業務網羅は自作しない）
