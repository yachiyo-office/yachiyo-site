## 使い方

1. HTMLをブラウザで開く
2. 薄い枠をクリックして編集
3. 「印刷 / PDF保存」

## 標準的な案件の流れと使う書式

1. 一次ヒアリング → 必要なら要件調査契約
2. 見積書 → 業務委託契約 → **着手金請求・入金・領収書**
3. **初回案内メール**（必要書類・振込案内）
4. 資料収集（預り証）・社内チェックリスト進行
5. 申請前：**残金請求・入金** → 委任状 → 申請
6. 許可後：完了報告・**書類返却証**

## 料金・支払いの基本方針

- 対外書類は時間単価ではなく項目加算
- 着手金＝報酬税込の半額のみ（法定費用・実費は含めない）
- 申請前に残金全額（報酬残＋法定費用＋実費）
- 出張交通費：一律2,000円（税込）。受任後は報酬から相殺可

## グレーゾーン案件

許可の見込みが不透明な場合は、本申請の前に要件調査契約（税込33,000〜55,000円目安）を使う。  
申請見送りでも調査費用は返還しない旨を事前説明すること。

## 使う前に埋める項目

- 振込口座
- 電話番号
- 行政書士登録番号
- 見積・請求・領収・契約の各番号ルール

## 注意

- 金額の自動計算はしない
- 委任状は行政庁指定様式がある場合はそちらを優先
- 本雛形は一般的な業務用ドラフトです。必要に応じて調整してください
- 市販の書式セットが必要になったら購入検討でよい（全業務網羅は自作しない）
